Where the Loops Come From

Four things you can grow yourself, and one rule underneath all of them

Frost: branching that carries nothing

Particles wander at random until they touch what is already there, and stick. Nothing plans this. Watch where the growth happens.

particles stuck: 0  ·  rings closed by accident: 0
What to notice A tip that sticks out slightly gets hit first, so it grows faster and shades the hollows behind it. The arms never join back up. But ask yourself: what would even travel along one of these branches? Nothing does. That is why frost is the odd one out in this whole set.

Rivers: water only goes one way

Rain falls on a random landscape. Every drop moves to whichever neighbouring square is lowest. Thicker lines carry more water.

streams drawn: 0  ·  loops found: 0  ·  outlets to the sea: 0
What to notice The loop counter never moves off zero, and it cannot. Every square sends its water to exactly one lower square, and you can never get back to where you started by only going downhill. The tree is forced by the rule, not chosen.

Shortest, or safest?

Click the map to add towns. The shortest possible network joining them is always a tree. Then start cutting links and see what that costs you.

towns: 0  ·  total length: 0  ·  loops: 0  ·  after cutting: nothing cut yet
What to notice Spare links always make the network longer, so they always cost more. The only thing you get back is what happens when a link breaks. If nothing ever breaks and nothing ever changes, you have wasted the money. That is the whole trade-off.

Slime mould: the same rule, twice

Every tube starts equal. Flow is sent between two food points, and any tube carrying a lot gets thicker while quiet tubes wither. The only thing you change is whether the deliveries stay the same or move around.

steps: 0  ·  surviving tubes: 0  ·  loops surviving: 0  ·  total tube length: 0
What to notice Run it on the first setting and the loop counter falls to zero: with one fixed delivery, everything spare gets thrown away. Switch to the second setting and loops survive, even though the mould is following exactly the same rule. Nothing about the creature changed. Only the uncertainty did.
