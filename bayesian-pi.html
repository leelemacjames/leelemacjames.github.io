Bayesian estimation of π

The standard Monte Carlo construction places random points uniformly in the square [−1,1] × [−1,1] and records whether each point lies inside the unit circle.

x² + y² < 1

The circle has area π and the square has area 4. Therefore the probability q of a random point falling inside the circle is

q = area of circle / area of square = π/4,   so   π = 4q.

After N points, with s points inside the circle, the usual point estimate is

π̂ = 4s/N.

That estimate says nothing directly about its uncertainty. Bayesian inference replaces the single value with a posterior distribution over q, and therefore over π.

Bayesian model

Likelihood

Each point is a Bernoulli trial. Conditional on q, the number of points inside the circle follows a binomial distribution:

P(s | q,N) = C(N,s) qˢ(1 − q)ᴺ⁻ˢ.

Prior and posterior

Using a uniform prior on q,

q ~ Beta(1,1),

the beta–binomial conjugate update gives

q | s,N ~ Beta(s + 1, N − s + 1).

Because π = 4q, the posterior for π is the same beta distribution stretched from [0,1] to [0,4]:

p(π | s,N) = ¼ pq(π/4 | s,N),   0 ≤ π ≤ 4.
The posterior mean is 4(s + 1)/(N + 2). This differs slightly from the raw Monte Carlo estimate 4s/N because the uniform prior contributes one prior success and one prior failure.

What the posterior shows

For very small N, the point estimate can be extreme. If every early point lands inside the circle, then π̂ = 4. The posterior does not treat that value as exact: it remains broad because only a few observations have been made.

As N increases, the posterior narrows and concentrates near π. The credible interval therefore makes explicit what the point estimate suppresses: how much uncertainty remains after the observed sample.
