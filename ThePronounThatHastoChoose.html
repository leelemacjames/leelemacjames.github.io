The pronoun that has to choose

A two-layer attention toy that carries one English sentence into French, on into Spanish, and back into English

Tap tired or wide and watch the French pronoun and the Spanish ending change; every number behind the change is laid out below, hop by hop, and the ideas that make sense of those numbers follow after the machine.

What the machine was doing

Why the pronoun is hard

The two sentences differ in a single adjective, and that adjective decides what it refers to, since an animal can be tired and a street can be wide. Pairs like this are called Winograd schemas, after the computer scientist Terry Winograd, and this particular pair became famous in 2017 when researchers at Google used it to illustrate the attention mechanism of the Transformer, the architecture underneath every large language model in use today.

English can leave the pronoun unresolved on the page, because it serves the animal and the street equally well and the reader quietly supplies the answer, whereas French forces a commitment, since l’animal is masculine and la rue is feminine, so choosing between il and elle amounts to deciding what the sentence means. Nothing inside the word it can settle that choice; the evidence sits three words further on, in the adjective, and in the background knowledge that tiredness belongs to living things while width belongs to roads.

A word becomes a list of numbers

A transformer replaces every token with an embedding, a list of numbers that you can picture as the coordinates of a point, or equally as an arrow drawn from the origin to that point. Each position in the list answers one question about the word, so the list for animal says yes to “is it alive?”, yes to “can it get tired?”, and records that its French and Spanish translations are masculine. In a trained model the list runs to thousands of entries and none of the questions has a human name, while the toy uses nine entries whose questions have been written down by hand.

The English word animal carries French and Spanish gender because, in a model that translates, a noun’s vector has to hold whatever its translations will later demand, and the model learns early that the thing called animal will require masculine agreement in both of the other languages.

The dot product measures agreement

Two lists of the same length can be compared by multiplying them position by position and adding the results, which is the dot product, written q·k = q₁k₁ + q₂k₂ + … + qₙkₙ. Positions where both lists are large and of the same sign add a lot, positions where either list is zero add nothing, and positions where the signs disagree subtract, so the total behaves like a meter of agreement between what one word asks for and what another word offers. Geometrically the same number equals |q| |k| cos θ, the lengths of the two arrows multiplied by the cosine of the angle between them, so arrows pointing the same way give a large positive result, arrows at right angles give zero, and arrows pointing apart give a negative one.

The two axes of the drawing are the tire and width entries, and the gold arrow is the pronoun’s query after it has read the adjective: with tired it points along the tiredness axis, with wide along the width axis. The animal’s key lies on the tiredness axis and the street’s on the width axis, so whichever key lines up with the query wins the dot product.

Turning a table on its side

When every token has a key, the keys are stacked as the rows of a table K, one row per token. Matrix multiplication always pairs a row of the left-hand matrix with a column of the right-hand one, so to pair the query with each key in turn the key table is turned on its side, rows becoming columns, which is the transpose Kᵀ. The query row then meets each key column, and each entry of the product is one dot product.

With many words asking at once, their queries are stacked into a matrix Q as well, and the product QKᵀ becomes a square grid whose entry in row i and column j is how strongly word i is interested in word j. The toy computes only the pronoun’s row of that grid, which is the row the “Transpose” button in the machine lets you watch being built.

From scores to shares: softmax

Raw dot products can be any size and any sign, so they are turned into shares of attention that are positive and add up to one. Softmax does this in two moves: it raises e to the power of each score, which makes every number positive and stretches the gap between the leader and the rest, because e7.6 is about two thousand while e5.4 is only about two hundred, and it then divides each result by their total.

sharej = escorej ⁄ Σm escorem

Every word with a score of zero still contributes e0 = 1 to the total, which is why the machine shows the minor words as a single row worth one each: they dilute the winner a little, and a model with sharper scores dilutes it less. Before the exponential the scores are divided by √d, the square root of the key length, because dot products of longer lists tend to be larger simply through having more terms, and the division keeps them in the range where the softmax can still tell candidates apart; the sharpness slider multiplies the scores, which plays the role that a learned scale, or its reciprocal the temperature, plays in a real model.

Attention(Q, K, V) = softmax( Q Kᵀ ⁄ √dₖ ) V

Handing over the value, keeping the residual

Each token also carries a value, the content it hands over if it is chosen, and the pronoun receives the weighted sum of the values, so a 90 per cent share of the animal and a 10 per cent share of the street delivers 0.9 × (−1) + 0.1 × (+1) = −0.8 in the French gender entry, a strongly masculine signal. That sum is added to the vector the pronoun already had, an addition called the residual connection, so information accumulates in a token as it passes through layers, which is why the first layer’s gathered property is still present when the second layer needs it.

Why two layers

The pronoun cannot find its referent in one step, because before reading the adjective it has no idea what property to look for. The first layer therefore asks a fixed question, “what is being said about me?”, and gathers the adjective; the second layer turns that gathered property into a new query, “which noun has this property?”, and the noun whose key agrees wins. Real models chain dozens of such steps, each layer able to ask questions that only make sense given what earlier layers have already gathered.

Three hops, three hiding places

Each hop runs the same arithmetic, yet the clue that identifies the referent moves to a different place in each language. Spanish usually omits the subject pronoun, since the verb ending already implies it, so the toy keeps an empty placeholder ∅ in its position and lets the adjective ending carry the answer; English on the way back has no gender to mark at all, so an error made earlier can vanish from the surface while the sentence still reads correctly.

The same two layers in NumPy 
import numpy as np

def softmax(z):
    e = np.exp(z - z.max())          # subtract max for numerical stability
    return e / e.sum()

# rows: The animal didn't cross the street because it was too tired .
# cols: anim tire width noun fr es state anaph pred
X = np.zeros((12, 9))
X[1]  = [1, 1, 0, 1, -1, -1, 0, 0, 0]   # animal
X[5]  = [0, 0, 1, 1,  1,  1, 0, 0, 0]   # street
X[7, 7] = 1                             # it (anaphor)
X[10] = [0, 1, 0, 0,  0,  0, 1, 0, 1]   # tired (predicate)
a = 7

# layer 1: the pronoun's query asks for a predicate
w1 = softmax(4 * X[:, 8])
carry = [1, 2, 4, 5, 6]                 # entries the value passes on
h = X[a].copy()
h[carry] += w1 @ X[:, carry]            # residual add

# layer 2: keys describe nouns only, so mask by the noun column
q = np.array([h[1], h[2], h[4], h[5], 2.0])
K = X[:, [1, 2, 4, 5, 3]] * X[:, [3]]
scores = 6 * (q @ K.T) / np.sqrt(5)     # q times K-transpose: one row of QK^T
w2 = softmax(scores)
fr = h[4] + w2 @ (X[:, 4] * X[:, 3])    # residual + weighted French gender
print(w2.round(3), "elle" if fr > 0 else "il")

What the toy leaves out

A trained model reaches behaviour like this through gradient descent over many heads and dozens of layers, with queries, keys and values produced by learned matrices acting on vectors whose entries have no names, and studies that probe real models, such as Clark and colleagues’ 2019 analysis of BERT, find individual heads that track coreference fairly well alongside others that spread the work across several layers. The nine labelled entries and hand-set weights here act as scaffolding that makes each multiplication visible, while the shape of the computation, a query meeting keys, a softmax over the scores and a weighted sum of values added back into the stream, is the shape a large model repeats billions of times.
